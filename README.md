# Telegram-бот для студента

Утром присылает сводку (расписание, погода, дела, ДЗ на сегодня, IT-новости), вечером — расписание и ДЗ на завтра, а перед парой напоминает о ней. Всё управляется инлайн-кнопками, команды нужны только для быстрого ввода.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Установите зависимости (нужен Python 3.9+):
   ```
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и впишите токен и ссылку на своё расписание (`ICS_URL`).
4. Запустите:
   ```
   python bot.py
   ```
5. Откройте бота в Telegram и отправьте `/start` — он запомнит ваш чат и будет отвечать только вам.

Чтобы бот работал круглосуточно, запустите его на VPS/Raspberry Pi/любом сервере (например, через `systemd` или `screen`/`tmux`). Если компьютер выключен — сообщения не придут.

## Что умеет

**Утренняя сводка** (по умолчанию 07:30): расписание, погода, ДЗ на сегодня, невыполненные дела, 3 новости IT.

**Вечерняя сводка** (по умолчанию 20:00): расписание на завтра и ДЗ на завтра. Выключается в настройках.

**Напоминание о паре** (по умолчанию за 15 минут): приходит один раз перед каждой парой, вместе с аудиторией и ДЗ по этому предмету. Можно выбрать 10, 15, 20, 30 минут или любое значение командой `/remind`.

**Домашние задания.** В меню нажмите «📖 ДЗ» → «➕ Записать ДЗ», выберите предмет из расписания и отправьте текст задания. Бот сам привяжет его к ближайшей паре этого предмета. В списке ДЗ задания сгруппированы по датам, выполненное отмечается кнопкой ✅, а ДЗ на сегодня и завтра попадают в утреннюю и вечернюю сводки и под саму пару в расписании. Быстрый ввод: `/hw Математика: № 5–10`.

**Расписание.** Экран дня переключается стрелками ‹ ›, на сегодняшнем дне прошедшие пары приглушены, а текущая отмечена 🟢.

## Команды

| Команда | Что делает |
|---|---|
| `/menu` | меню с кнопками |
| `/brief` | утренняя сводка прямо сейчас |
| `/today`, `/tomorrow` | расписание на сегодня / завтра |
| `/next` | ближайшая пара |
| `/hw` | список домашних заданий |
| `/hw Предмет: текст` | записать ДЗ на ближайшую пару предмета |
| `/list` | список дел |
| `/add текст` | добавить дело |
| `/done N`, `/del N`, `/clear` | отметить, удалить, убрать выполненные |
| `/weather`, `/news` | погода, IT-новости |
| `/time ЧЧ:ММ` | время утренней сводки (МСК) |
| `/evening ЧЧ:ММ` или `/evening off` | время вечерней сводки / выключить |
| `/remind минуты` или `/remind off` | за сколько минут напоминать о паре / выключить |

Данные (чат, настройки, дела, ДЗ) хранятся в `data.json` рядом с ботом.
Погода — Open-Meteo (без ключа), новости — RSS Хабра (источник можно сменить через `NEWS_URL` в `.env`, количество в сводке — `NEWS_COUNT`).
